# Learnings — Foundernees

_Capture the transferable lesson only — never keys, credentials, or proprietary internals._

## What worked
- **Turning a values promise into a CI number.** "Built for the office boys of the world"
  is the kind of line that dies quietly in month three. Encoding it as two enforced
  numbers — LCP/weight on a throttled Android, Flesch-Kincaid grade ≤ 8 — means a future
  session cannot trade it away for a nicer hero animation without a failing build.
  Transferable: any product whose differentiator is a *value* should convert that value
  into a check before the first line of code.

## What we would do differently (pitfalls)

| Pitfall | The fix | Guardrail it became |
|---|---|---|
| A headline target ("the first 100K builders") that reads as an output but only works as an input — the implied funnel needed ~10M reach and would have made an unsigned partnership the year's single point of failure | Do the funnel arithmetic *before* publishing the number; split the stated figure into input (onboarded) and output (shipped) | `goal.md` Layer 1 states the arithmetic inline; `decisions/0001` records the split and its revisit trigger |
| A page-weight budget measured with `fetch().arrayBuffer()` reads **uncompressed** bytes — fetch decompresses transparently and the server sends no content-length. The first run reported 610 KB against a 400 KB budget and "failed" a site that actually ships 186 KB | Gzip the body yourself at the same level the server uses, and state in the script which number is being measured | `tests/weight.ts` measures compressed and says so in its header comment; the budget line prints "gzip-compressed" so nobody re-litigates it |
| A weight budget pushed the first design into *restrained* and it read as a whitepaper — the operator's words: "lackluster, too plain, not exciting at all." Optimising for the constraint quietly became the aesthetic | Buy excitement with CSS and SVG instead of assets: display type at 12vw, full-bleed inverted bands, a drawn funnel, grain from one inline turbulence filter, scroll reveals via `animation-timeline: view()`. The whole redesign cost 6 KB | Encoded as a note at the top of `app/globals.css` listing what each effect costs — so the next session reaches for CSS before reaching for an image |
| A page-weight check that only scanned HTML for assets **silently missed the web font**, because fonts are referenced from CSS. It reported 202 KB while the page actually transferred 221 KB — a budget that under-reports is worse than no budget | Detect the font's usage marker in the HTML and charge the page for the file; woff2 is pre-compressed so its file size *is* its transfer size | `tests/weight.ts` now adds CSS-referenced fonts to the per-page total, with a comment saying why the naive scan was wrong |
| Decorative SVG sized by the section's **height** scaled ~3.6× on a short wide band — a chain became huge abstract ovals, and its "break" was hidden behind opaque headline type, so the one thing the art existed to show was invisible | Size fold art by **width** with the aspect ratio preserved, and place the meaningful detail in open ground beside the type, never behind it. Then mask the art off the copy with a linear-gradient so legibility always wins | Written into each art component's header comment; the mask trick is reused by all three pieces |
| A chain drawn as single-stroke `<ellipse>` elements "looked exactly like ovals" (operator's words) — because it *was* ovals. A stroked ellipse has no inner edge, so nothing reads as metal, and alternating rx/ry only produces wide ovals and tall ovals | A link is a **ring with thickness**: outer + inner stadium in one path under `fill-rule="evenodd"`. A chain then needs two more things — alternating 90° planes, and **interlock by painting order** (all even links, then all odd on top, so one genuinely occludes the other at each crossing) | Written into `components/art/BrokenChain.tsx` as a header comment recording both failed attempts, so nobody re-derives it |
| The fix above still failed on the second attempt: individual links past the break were each rotated and dropped, which pulled them out of one another and turned the tail to mush | **Segments move, not links.** The fallen half is one `<g>` rotated about its own first link, so the links inside stay locked while the whole run swings down. Interlock is a property of the sequence, not of any single element | Same header comment; the `Segment` component makes the unit of movement explicit in the code's shape |
| Shipped the first Nastaliq font found (Noto Nastaliq Urdu) without comparing alternatives — it is correct Urdu but nearly uniform in stroke weight, so it reads as typesetting rather than calligraphy | Subset **all** candidates to the exact phrase, render them side by side at display size, and pick by eye. Gulzar won on qalam contrast and was *smaller* than the incumbent (24.7 vs 29.1 KB) — the comparison cost ~10 minutes and improved the result at negative byte cost | The comparison table lives in `public/fonts/README.md` with each font's verdict, so the choice is auditable and re-runnable |
| A "beautiful calligraphy" request looked like a font problem, but the best free Nastaliq was already in place — and the obvious next candidate, SIL's Awami Nastaliq, is **unusable on the web**: it depends on the Graphite shaping engine no browser implements, so it renders as disconnected letters in the wrong order | Test the font in a real browser before believing its reputation. When the font is already the ceiling, move the effort to **treatment** — here, a tapered qalam swash as a filled SVG outline (strokes cannot taper, and constant width is what makes digital calligraphy look fake) | Recorded in `components/HarFanMaula.tsx` and `public/fonts/README.md` so the Awami dead end is not re-walked |
| A brand accent picked for beauty rather than from the palette — gold on a green-and-ink site — "stands out completely" in the wrong way | Accent colours come from the existing token set, not from taste applied fresh per component. The fix was one token swap to the green already used for "billion" and the stage roles | The e2e suite now asserts the phrase's exact computed colour, so a future drift off-palette fails a test rather than shipping |
| Two pages saying the same thing (`/manifesto` repeating the home page) is duplicate content — it splits ranking authority and gives the reader two doors to the same room | One page per idea. Fold the text into the canonical page, anchor the nav to a section, and **308-redirect the retired URL** so nothing 404s and its authority carries over | `next.config.ts` holds the redirect with the reasoning inline; an e2e test asserts the redirect still lands on the right section |
| A straight chain reads as a rigid bar. The operator's word for what was missing — *jhol* — is the sag, and it is most of a chain's character | A hanging chain is a **catenary**, `y = a·cosh(x/a)`. Place links by **arc length** (`x = a·asinh(s/a)` inverts it exactly — spacing by x bunches them where the curve steepens) and rotate each to the tangent. Giving the two halves different `a` — tauter where still anchored, deeper where it let go — communicates the break with no other cue | Encoded in `BrokenChain.tsx`; the general lesson is that physical objects have a governing equation, and using it beats eyeballing a curve |
| Decorative art needed a light sweeping across it, but a `clipPath` clipped the stroked crescent to nothing — clip paths clip to **fill** geometry only | Use an SVG `<mask>`: it renders its contents and uses their luminance, so strokes are captured. Draw the artwork once in white inside the mask, then paint a base fill and the moving highlight through it | `ArtSurface.tsx` is now the shared surface for all fold art, so the technique is used once rather than re-derived per component |
| A CSS animation on `transform` silently overrode Tailwind's positioning classes, which also use `transform` (`-translate-y-1/2`) — the art jumped out of place the moment it animated | Split the concerns across two elements: a wrapper owns *where* (transforms safe), the inner element owns *how it moves*. Never let layout and animation share a property | Written into `ArtSurface.tsx`'s header; applies to any scroll-linked effect on a positioned element |
| Next.js injects its own `role="alert"` route announcer, and Playwright's `getByLabel` matches substrings — so `getByRole("alert")` and `getByLabel("Organisation")` both hit two elements and fail on strict mode | Scope assertions to the component under test (`form [role=alert]`) and prefer `getByRole("textbox", { name })` over `getByLabel` when a radio's accessible name shares words with a field | Encoded in `tests/e2e/site.spec.ts`; transferable to any Next + Playwright suite |
