# 2026-08-30

- **Test a portable starter in an actual scratch repo, not just by reading the
  ported code.** Extracting `brain/`'s core into `templates/brain-starter/`
  looked complete on paper; copying it into a throwaway fake repo and running
  ingest/ask/freshness/rebuild against real files surfaced a real design
  question (does the starter indexing its own README count as noise?) that
  reading the code alone wouldn't have raised. → `brain/decision-log/2026-08-30-brain-core-extracted-as-starter.md`
- **When porting a pattern into a reusable form, cutting weight is itself a
  decision, not just tidying.** Dropped the Phase-C stub tables, the
  products-aware corpus walk, and `--context` mode from the starter — each
  one Hamzaish-specific rather than general to the pattern. Worth recording
  *what* was cut and *why*, since "thinner than the original" is exactly the
  kind of call that looks right until an adopter needs the missing piece on
  day one.
